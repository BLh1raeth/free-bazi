# 子平古籍基础表诀 v1

版本标识：`sanming-basic-v1`

本项目把神煞视为“按指定表诀命中”的可复核标签，不把它当作独立的吉凶结论。不同古籍、流派与现代软件可能采用年干、日干、年支、日支等不同起法，所以界面会明确显示本版本口径。

## 本版本口径

- 天乙贵人：以日干查四柱地支。
- 禄神：以日干查四柱地支。
- 驿马、华盖、将星：分别以年支、日支查四柱地支；同一柱被两个基准命中时合并显示依据。
- 只列命中与依据，不生成吉凶、健康、投资或重大人生决策结论。
