# 三命通会常用神煞表 v3

版本标识：`sanming-common-v3`

## 使用边界

- 本版本固定为 39 个可确定查表的名称，计算函数只返回“是否按表命中”，不输出吉凶断语。
- 同一柱命中多个名称时全部保留；同一名称由年支和日支同时命中时合并依据，不丢弃重复来源。
- 神煞流派众多。“完整”指本文件列出的 v3 目录完整执行，不代表混用所有民间版本。
- 规则变化必须升级版本、保留旧文档，并补映射测试；禁止静默修改口径。

## 固定目录

1. 日干查：天乙贵人、禄神、金舆、文昌贵人、太极贵人、文星贵人、天印贵人、红艳煞、阳刃。
2. 月支查：天德贵人、月德贵人、天德合、月德合、德秀贵人、天医。德秀贵人仅在月令对应的德、秀两组干同时出现时命中，不把“德”“秀”拆成单字神煞。
3. 年支或日支三合组查：驿马、华盖、将星、劫煞、亡神、灾煞、六厄、咸池。
4. 年支查：红鸾、天喜、孤辰、寡宿、丧门、吊客、官符、病符、死符。
5. 全局支组合查：天罗、地网。
6. 日柱表查：阴阳差错、八专、九丑、孤鸾、魁罡。

共 39 项，代码目录由 `SHEN_SHA_CATALOG` 导出，测试会检查数量与名称唯一性。

## 主要文本来源

- 《三命通会》卷三：金舆、驿马、天乙、天月德、太极贵、学堂词馆、德秀、劫煞亡神、羊刃、灾煞、六厄、孤辰寡宿、天罗地网及总论诸神煞。

## 测试约束

- 日干查支必须遍历十干与十二支；月德、天德必须遍历月支和六十甲子候选柱。
- 三合组规则必须覆盖十二个基准支。
- 日柱表至少各设一个阳性样本，且目录数量和名称唯一性必须测试。
- 四柱直排必须验证八字原样生成、十神随日主计算、神煞可多项命中，并确认不会伪造起运。
