# 子平古籍常用表诀 v2

版本标识：`sanming-common-v2`

本项目把神煞作为“按指定表诀命中”的可复核标签，不把它当作独立的吉凶结论。不同古籍、流派与现代软件可能采用不同起法，本版本固定下列口径，界面只列命中项，不输出确定性断语。

## 取用口径

- 日干查四柱：天乙贵人、禄神、金舆、文昌贵人、阳刃。
- 月支查四柱：天德贵人、月德贵人。天德表中的乾、坤、艮、巽分别落实为亥、申、寅、巳。
- 年支与日支分别查四柱：驿马、华盖、将星、劫煞、亡神；同一柱被两个基准命中时合并依据。
- 咸池：除三合局对应支外，基准柱纳音还必须与该三合局五行同类。没有满足纳音条件时不列出。
- 年支查四柱：红鸾、天喜。以子年红鸾在卯、天喜在酉为起点逆数；天喜永远与红鸾相对。
- 只列规则命中，不生成健康、投资、婚姻或人生重大决策结论。
