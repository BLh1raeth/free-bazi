# 隐私设计

## 数据流

1. 用户在浏览器填写姓名（可选）、出生日期时间、城市与规则；
2. Zod 在浏览器验证；
3. 历法模块在浏览器计算；
4. 默认将输入写入 `sessionStorage`，键为随机 UUID；
5. URL 只保存 UUID 与查看状态，不含姓名和完整生日；
6. 用户主动勾选后才同时写入 `localStorage`；
7. 导出在本机动态生成，不调用外部接口。

## 不收集

- 不注册、不登录；
- 无数据库、分析脚本、广告 SDK；
- 不出售出生信息、排盘记录或行为数据；
- 不把姓名或出生资料发送到第三方服务；
- `.env.example` 不含真实密钥。

## 用户控制

命盘页“清除本地记录”会删除前缀为 `qinglan:chart:` 的 sessionStorage 与 localStorage 数据。匿名导出会把称呼显示为“匿名命盘”。

## 威胁与限制

- 同一浏览器中的其他脚本若发生 XSS 可能访问 Web Storage，因此项目不渲染用户 HTML，不使用 `dangerouslySetInnerHTML`；
- 随机 UUID 不是加密密钥，但出生资料不在 URL 或服务器中；
- 用户下载的 PNG / PDF 由用户自行保管；
- 浏览器扩展、设备恶意软件与共享操作系统账户不在 Web 应用可完全防御的范围内。
