# 八字排盘规则

## 统一数据模型

原局、大运、流年、流月、流日、流时统一使用 `Pillar`：干支、天干/地支五行阴阳、十神、藏干、纳音、十二长生和空亡。关系模块只接收 `Pillar[]`，不依赖 React。

## 四柱

1. 年柱按立春的精确交接瞬间换年。
2. 月柱按十二节（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）换月。
3. 日柱默认采用晚子初 23:00 换日（sect 1）；用户可改为当地 00:00 换日（sect 2）。
4. 时柱按当地民用时十二时辰；出生时刻未知时为 `null`。
5. 节令是全球同一瞬间：用户民用时由 IANA 时区解释，再转为东八区输入历法库做年/月柱判定。

## 十神、藏干、五行

十神由日主与目标天干的五行生克和阴阳同异纯函数计算。藏干表独立维护，主气/中气/余气权重透明列示。五行提供两种口径：

- 明字：八个干支各计 1；
- 藏干加权：四个天干各计 1，四个地支按藏干比例各拆分为总计 1。

该统计不是旺衰分析，不给出“缺什么就补什么”的建议。

## 纳音、十二长生与空亡

纳音按完整六十甲子两柱一组表；十二长生按十天干起长生支，阳干顺行、阴干逆行；空亡按六旬计算。所有映射均有循环边界测试。

## 大运与起运

- 阳年男、阴年女顺排；阴年男、阳年女逆排；
- 顺排取出生后下一个“节”，逆排取出生前上一个“节”；
- 真实时间差按三天一岁、一日四个月折算，余数换算为天；
- 大运干支从月柱按顺逆每次移动一位，每步十年，共十二步；
- 未指定性别时不生成大运，避免暗自选择流派。

起运折算存在不同门派取整方式，本项目明确显示当前公式；结果应理解为所选规则下的排盘数据。

## 流运懒计算

- 流年：在产品支持范围内批量生成；
- 流月：选择流年后，以立春至下一立春的 13 个节令边界生成 12 月；
- 流日：选择流月后，只生成该节令月内当地中午归属该月的日期；
- 流时：选择日期后生成十二时辰；
- 同一出生输入的原局使用内存 memoization；导出库动态导入。

## 干支关系

天干识别五合、同类、生、克；地支识别六合、三合、三会、六冲、刑、自刑、六害、六破。三合与三会必须在当前上下文完整出现才标记。关系只客观列示，不转化为确定性吉凶。

## 胎元、命宫、身宫

首版展示 `lunar-typescript` EightChar 常用公式结果。由于流派差异，尚未提供规则切换；界面和 README 已标为限制。

## 真太阳时

首版关闭。完整实现必须同时处理经度与时区中央经线之差、均时差、历史 DST、日期跨越和节令瞬间。未完成独立验证前不输出近似值。
